# assets
Um repositorio apenas para subir imagens pra quem precisar, apenas suba imagem e use ||  A repository solely for uploading images for anyone who needs them; just upload the image and use it.


Criei esse repositorio apenas para facilitar a usar imagens por link, tava precisando e aproveitei para deixar de ultilidade para quem quiser e/ou precisar

I created this repository simply to make it easier to use images via links; I needed it myself, so I decided to make it available for anyone else who might want or need it.
